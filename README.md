# Kargo Kutusu İçindeki Havanın Mülkiyet Davası

## Kurumsal Kimlik

Bu yazılım, kargo kutusunun kapağı kapanır kapanmaz içerde mahsur kalan havanın **zilyetlik**, **mülkiyet** ve **teslim** haklarını savunan ulusal ölçekte bir hukuki üretim hattıdır.

Hava, teslim alınmamıştır. Hava, tartılmamıştır. Hava, irsaliyede "içerik: belirsiz sessizlik" diye geçmektedir. Bu kabul edilemezdir.

## Neden Bu Kadar Ciddiyiz?

Çünkü komik değiliz. Komik olan kutunun içindeki boşluktur. Boşluk ise hukuken "şey" değildir; şey olmayan şeyin davası ise şeylerin en şeyidir.

ISO-YOK / TS-HAVA-404 sertifikalıdır.

## Kurulum

```bash
python3 dava.py
```

Bağımlılık: Python 3. Sadece standart kütüphane. Avukat getirmeyiniz, yazılım zaten avukattır.

## Kullanım

Program şunları üretir:

1. Dava dilekçesi
2. Delil listesi (kutu, bant sesi, kuryenin bakışı)
3. Keşif talebi (kutu açılsın, hava tartılsın)
4. İhtiyati tedbir (üst üste konmasın)
5. Feragatname (asla feragat etmez)
